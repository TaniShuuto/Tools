## 4. Phase 2(自動追従)— 合格基準 D-6(CONTRACT_PHASE2.md P2-10)

自宅 PC、同じ試験シーン、Painter の最終出力 1024²・6 マップ。2026-10-18 に 16 ジョブ実行、すべて成功、3D プローブ全合格。変換 1.7〜2.8 秒。

| D-6 | 内容 | 結果 |
|---|---|---|
| 1 | Painter の Final 書き出しへの自動追従 | 合格(3 回以上連続) |
| 2 | 自動追従オフで `STALE`(入力が新しい)→「変更を反映する」で反映 | 合格 |
| 3 | 原本に戻した TS は自動で変換しない | 合格 |
| 4 | 変換中の書き出しは保留し、完了後に 1 回だけ再変換 | 合格。2 秒の落ち着き待ちの間に続いた書き出しは 1 回にまとまる(仕様どおり) |
| 5 | 窓を閉じて開き直したときのジョブの引き継ぎ | 合格(窓を閉じても変換は継続、開き直しても直さなくても反映) |
| 6 | キルスイッチで待ち行列・保留を破棄し、従来の動作に戻る | 合格 |
| 7 | Live Sync 本体に差分が無い | 合格(Phase 2 の PR #24〜#28 で `maya_live_sync.py` は無変更) |
| 8 | UV 編集(移動・回転・縫合/切断)の後に「変更を反映する」が出て、1 回で反映 | 合格 |
| 9 | UV 自動反映 | 合格(操作は重くならない) |
| 10 | 2 TS を 4096² で同時変換したときの操作とメモリ | **未実施**(試験シーンの TS が 1 つのため) |
| 11 | 1 万面で UV 指紋の取得が 200 ms 以内 | 合格(事前の実測で約 0.9 ms) |

UV 指紋の実測(P2-0'、mayapy バッチ): 400 面 0.1 ms 以下、1 万面 約 0.9 ms、10 万面 約 8 ms。移動・回転・切断・縫合・平面投影・自動展開のすべてで直後に変化を検知、UV 不変の操作では変化なし。

## 5. 実機で分かったこと(記録)

- Painter 側の設定は「設定を保存」を押すまで書き出しに反映されない(画面は 512 でも実際は保存済みの 4096 で書き出された)。改善は利便性向上の作業へ(`REVIEW_R2_ui.md` R2-08)。
- Painter は、書き出しが成功でなくても完了の印を書く。自動追従の既知の制約(CONTRACT_PHASE2.md P2-9)。
- `mesh_uuids_changed` の警告が 1 回出た(原因の操作は未特定。変換・プローブは合格)。
- Painter 12.1.5 が新規プロジェクト作成時に 1 回クラッシュ(Live Sync の処理前。関連は薄いと判断)。
