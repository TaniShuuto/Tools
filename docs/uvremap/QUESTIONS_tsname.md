# 指揮役への質問・記録(レーン C2b・TS名=シェーダー名)

契約 `CONTRACT.md` §2 のキー名・配列の形は変えていない。
`list_texture_sets` / `collect_arrays` の TS名を、Phase 0(V2・V7、2026-10-16)で
確認した Painter 12.0.0 のテクスチャセット名(= Maya のシェーダー名)に合わせた。
以下は実装側で決めず、未確認のまま残す点。

## T1. シェーダー名に名前空間や記号が含まれるときの Painter 側の名前 — 未確認

Maya のノード名が `ns:matA` のように名前空間付きのとき、または
空白・スラッシュ・Unicode などを含むとき、Painter のテクスチャセット名が
そのままか、区切り文字が変わるかは未確認。この作業では Maya が返すノード名を
そのまま TS名に使う。正規化はしていない。

## T2. FBX 以外の受け渡し形式 — 未確認

確認済みの事実は、Maya 2026 から書き出した三角形化 FBX を Painter 12.0.0 に
読んだ結果だけ。OBJ / USD / ABC などでは TS名の取り方が違う可能性がある。
形式ごとの差は推測していない。

## T3. シェーダーが接続されていないグループの名前 — 未確認

`<SG>.surfaceShader` に何も繋がっていないグループを Painter がどう呼ぶかは未確認。
実装はグループ名をキーにし、要素に `ts_name_unresolved: True` を付けるだけにする。
Painter 側の名前を推測して補わない。
