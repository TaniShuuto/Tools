# V9: 三角形化した FBX を Painter で使う(手動)

所要時間の目安: 15分。**利用者の既存プロジェクトでは行わない。**

Maya 側の出力は `v9_triangulated_fbx.py` または `run_maya_all.py` が
`phase0/scratch/phase0_v9b_triangulated.fbx` を書く(四角形メッシュを
`FBXExportTriangulate -v true` で出力)。

## Painter での確認

1. Painter で **新規プロジェクト**(テスト専用。保存するなら名前に `phase0` を含める)。
2. メッシュに `phase0_v9b_triangulated.fbx` を指定する。自動展開はオフでよい。
3. 読み込めたか、欠けや異常な割れが無いかを見る。
4. 適当にペイントできるか。
5. 書き出し(既存の Live Sync でも、標準の Export でも可)がエラーなく終わるか。

## v9b で変えた点(2026-10-16)

- 平面と立方体の UV は重ならない配置(平面は左下、立方体は右上。どちらも 0〜1 の内側)。
  UV エディタ/Painter の UV 表示で、重なっていないことを目で確認する。
- マテリアルは 2 つ。平面は `phase0_matA`(シェーディンググループ `phase0_sgA`)、
  立方体は `phase0_matB`(同 `phase0_sgB`)。シェーダー名とグループ名をわざと別にしてある。
- Painter では **テクスチャセットが 2 つ** できるはず。名前が `phase0_matA` / `phase0_matB`
  (シェーダー名)か `phase0_sgA` / `phase0_sgB`(グループ名)かを確認する。
  V2 と V7 を、プロジェクトを開いたまま再実行すると、結果 JSON にも出る。
